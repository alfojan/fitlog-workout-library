# FitLog — Workout Library

FitLog is a dark-themed workout library application built with Next.js. Users can explore workouts, view workout details, create a daily workout plan, and save workouts for later.

## Live Website

[Visit FitLog](https://fitlog-workout-library-u3q2.vercel.app/)

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Hot Toast

## Features

1. **Workout Library:** Explore 12 different workouts covering major muscle groups.
2. **Workout Details:** View workout descriptions, equipment, difficulty, sets, reps, and instructions.
3. **Today's Plan:** Add up to 5 workouts to your daily workout plan.
4. **Saved Workouts:** Save your favorite workouts for later.
5. **Workout Tracking:** Mark workouts as completed and track total exercises, minutes, and calories.
6. **Sorting:** Sort workouts by duration, calories, and rating.
7. **LocalStorage:** Keep your plan and saved workouts after refreshing the browser.
8. **Responsive Design:** Works on mobile, tablet, and desktop devices.

## Installation

Clone the repository:

```bash
git clone https://github.com/alfojan/fitlog-workout-library.git
```

Go to the project directory:

```bash
cd fitlog-workout-library
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
